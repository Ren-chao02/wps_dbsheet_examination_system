# WPS 多维表格考试系统 — 知识点总结

> 本文档梳理系统中考察学生的全部知识点，数据来源于能力图谱（`packages/server/src/data/capability-graph.ts`）、判分规则引擎（`packages/server/src/engine/rule-engine.ts`）及种子题库（`packages/server/prisma/seed.ts`）。

---

## 一、总体概览

| 维度 | 数量 | 说明 |
|------|------|------|
| 能力域 | **6 个** | 表操作、字段类型、字段属性、视图配置、表单、记录操作 |
| 能力点 | **66 项** | 每项对应一个可独立考察的 WPS 多维表格操作技能 |
| 判分规则 | **26 种** | 与能力点关联的自动判分 handler |
| 题目类型 | **5 种** | 建表、加字段、配视图、建表单、综合 |
| 难度等级 | **3 级** | 简单、中等、困难 |
| 判分方式 | **3 类** | 自动判分(auto)、需人工复核(needsReview)、纯人工(manual) |

---

## 二、六大能力域详解

### 1. 表操作（tables）— 6 项

考察学生对工作表的创建、命名、管理等基础操作。

| 能力点 | 说明 | 判分方式 | 默认难度 | 关联规则 |
|--------|------|----------|----------|----------|
| 创建工作表 | 在多维表格中创建新的工作表 | 自动 | 简单 | check_table_exists |
| 重命名工作表 | 修改已有工作表的名称 | 自动 | 简单 | check_table_name |
| 管理表字段 | 在表中添加、删除字段，确保字段完整性 | 自动 | 中等 | check_table_fields, check_field_count |
| 多表协作 | 创建多张工作表并建立关联 | 自动 | 困难 | check_table_count, check_table_exists |
| 设置主字段 | 设置表的主字段（第一列） | 需复核 | 中等 | check_field |
| 删除工作表 | 删除不需要的工作表 | 自动 | 中等 | check_table_count |

---

### 2. 字段类型（fields）— 29 项

考察学生对各种字段类型的创建和配置能力。按难度分为基础字段、业务字段、高级字段三组。

#### 2.1 基础字段（10 项）

| 能力点 | WPS 类型 | 用途 | 默认难度 |
|--------|----------|------|----------|
| 文本字段 | SingleLineText | 姓名、编号等单行文本 | 简单 |
| 富文本字段 | MultiLineText | 描述、备注等多行文本 | 简单 |
| 数字字段 | Number | 金额、数量等数值 | 简单 |
| 货币字段 | Currency | 价格、工资等货币数据 | 简单 |
| 百分比字段 | Percent | 完成率、折扣率等 | 简单 |
| 日期字段 | Date | 出生日期、入职日期等 | 简单 |
| 时间字段 | Time | 签到时间、时长等 | 简单 |
| 复选框字段 | Checkbox | 是否完成、是否通过等布尔值 | 简单 |
| 等级字段 | Rating | 评分、优先级等（星级） | 简单 |
| 附件字段 | Attachment | 图片、文档等文件 | 简单 |

#### 2.2 业务字段（11 项）

| 能力点 | WPS 类型 | 用途 | 默认难度 |
|--------|----------|------|----------|
| 电话字段 | Phone | 联系电话（自带格式校验） | 简单 |
| 邮箱字段 | Email | 电子邮箱（自带格式校验） | 简单 |
| 超链接字段 | Url | 网址（可点击跳转） | 简单 |
| 地址字段 | Address | 地址（支持省市区级联） | 中等 |
| 级联选项字段 | Cascade | 省市区、分类层级等多级选择 | 困难 |
| ID 字段 | ID | 自动生成唯一标识 | 简单 |
| 进度字段 | Complete | 用进度条表示完成度 | 简单 |
| 联系人字段 | Contact | 关联团队成员，常用于任务分配 | 中等 |
| 备注字段 | Note | 带格式的备注内容 | 简单 |
| 单选字段 | SingleSelect | 分类状态（如出勤/请假/缺勤） | 简单 |
| 多选字段 | MultipleSelect | 多标签分类（如技能标签） | 简单 |

#### 2.3 高级字段（8 项）

| 能力点 | WPS 类型 | 用途 | 默认难度 | 判分方式 |
|--------|----------|------|----------|----------|
| 关联字段 | Link | 关联其他工作表的记录 | 困难 | 自动 |
| 引用字段 | Lookup | 引用关联表的字段值 | 困难 | 自动 |
| 自动编号字段 | AutoNumber | 自动生成递增编号 | 简单 | 自动 |
| 创建人字段 | CreatedBy | 自动记录记录创建者 | 简单 | 自动 |
| 创建时间字段 | CreatedTime | 自动记录创建时间 | 简单 | 自动 |
| 修改人字段 | LastModifiedBy | 自动记录最后修改者 | 简单 | 自动 |
| 修改时间字段 | LastModifiedTime | 自动记录最后修改时间 | 简单 | 自动 |
| 公式字段 | Formula | 通过公式自动计算字段值 | 困难 | 需复核 |

> **关联字段**可额外验证关联目标表（check_field_link_target），是多表协作的核心。
> **公式字段**的公式表达式 Schema 不返回详情，需人工复核。

## 三、判分规则引擎（26 种）

判分规则是自动评分的核心，与能力点一一对应。

### 表级规则（4 种）

| 规则 | 说明 | 判分逻辑 |
|------|------|----------|
| check_table_exists | 验证表是否存在 | 表名模糊匹配(includes) |
| check_table_name | 验证表名是否正确 | 表名模糊匹配(includes) |
| check_table_count | 验证表数量 | 数量比较(eq/gte) |
| check_table_fields | 验证表包含所有指定字段 | 字段名集合包含检查 |

### 字段级规则（8 种）

| 规则 | 说明 | 判分逻辑 |
|------|------|----------|
| check_field | 验证字段存在及类型 | 字段名 + 类型(canonicalType) 匹配 |
| check_field_count | 验证字段数量 | 数量比较 |
| check_field_required | 验证字段必填 | field.required === true |
| check_field_options | 验证选项值列表 | 精确(exact)或包含(contains)匹配 |
| check_field_format | 验证字段格式 | numberFormat 模糊匹配(includes) |
| check_field_unique | 验证字段唯一约束 | field.uniqueValue === true |
| check_field_link_target | 验证关联目标表 | Link 字段的 linkSheet 匹配 |
| check_field_formula | 验证公式表达式 | 需人工复核（Schema 无详情） |

### 视图级规则（5 种）

| 规则 | 说明 | 判分逻辑 |
|------|------|----------|
| check_view_exists | 验证视图存在 | 视图名模糊匹配 |
| check_view_type | 验证视图类型 | view.type 精确匹配 |
| check_view_filter | 验证视图筛选 | 需人工复核（Schema 无详情） |
| check_view_sort | 验证视图排序 | 需人工复核 |
| check_view_group | 验证视图分组 | 需人工复核 |

### 表单级规则（4 种）

| 规则 | 说明 | 判分逻辑 |
|------|------|----------|
| check_form_exists | 验证表单存在 | Form 类型视图存在 |
| check_form_fields | 验证表单字段 | 表单字段集合包含检查 |
| check_form_field_required | 验证表单字段必填 | 字段必填属性检查 |
| check_form_settings | 验证表单设置 | 需人工复核（Schema 无详情） |

### 记录级规则（5 种）

| 规则 | 说明 | 判分逻辑 |
|------|------|----------|
| check_record_exists | 验证记录存在 | 记录数 > 0 |
| check_record_value | 验证记录值（包含匹配） | 字段值 contains 匹配 |
| check_record_value_exact | 验证记录值（精确匹配） | 字段值 String() 精确比较 |
| check_record_count | 验证记录数量 | 数量比较(eq/gte) |
| check_linked_record | 验证关联记录 | Link 字段的 linkSheet 匹配 |

## 七、判分方式分布

| 判分方式 | 数量 | 说明 |
|----------|------|------|
| 自动判分 (auto) | **49 项** | 系统通过 Schema/API 自动验证，无需人工 |
| 需人工复核 (needsReview) | **16 项** | Schema 不含详情，系统标记后由教师复核 |
| 纯人工 (manual) | **1 项** | 隐藏字段配置，无对应 handler |

> 自动判分率约 74%，需人工介入的考点集中在：视图筛选/排序/分组、表单布局设置、公式表达式、字段默认值。

## 八、知识点依赖关系

部分能力点有前置依赖，出题时应确保前置能力已考察或已具备：

```
table.create（建表）
  ├── table.rename（重命名）
  ├── table.fields_manage（管理字段）
  ├── table.multi（多表协作）
  │     └── field.link（关联字段）
  │           ├── field.lookup（引用字段）
  │           └── view.tree（树形视图）
  ├── field.single_select（单选字段）
  │     ├── view.kanban（看板视图）
  │     └── field.cascade（级联选项）
  ├── field.date（日期字段）
  │     ├── view.gantt（甘特图视图）
  │     └── view.calendar（日历视图）
  └── form.create（创建表单）
        ├── form.fields（表单字段配置）
        │     └── form.field_required（表单字段必填）
        └── form.layout（表单布局设置）
```
